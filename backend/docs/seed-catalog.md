# Каталог начального наполнения

Это стартовый набор справочников, а не полный отраслевой классификатор. Карточек людей,
собак, мероприятий и медицинских процедур в seed нет.

Базовые значения проекта отмечены отдельно от значений исходных документов.
ID внутри каждой таблицы начинаются с 1 в приведённом порядке; бизнес-логика
не должна зависеть от этих чисел. После вставок последовательности синхронизируются.

## vaccine_type

Начальный набор пуст. Конкретные препараты, производители и сроки действия
должны подтверждаться источниками; универсальные значения не задаются.
Названия заболеваний не заменяют конкретные препараты вакцин.

Ветеринарный модуль не добавляет препараты автоматически. Ветеринар может
добавить препарат через API с двумя подтверждёнными интервалами и единицами days/months; старые
неизвестные периоды не угадываются. См. [veterinary.md](veterinary.md).

## Откат

Down удаляет только начальные ID и не использует CASCADE. При наличии ссылок
из рабочих записей PostgreSQL отклонит откат. Полный откат схемы удаляет данные
и проверяется исключительно в одноразовой тестовой БД.

## Миграция 00009: печатные карточки

Миграция 00009 добавляет два типа печатных форм:
«Карточка члена клуба» и «Карточка собаки». Итого document_type содержит девять
значений; основной seed 00002 сохраняет первоначальные 68 строк в 17 справочниках,
после 00009 — 70 строк. Ветеринарное заключение использует «Ветеринарная справка».
Личные данные и демонстрационные файлы не добавляются в рабочую базу.

## Миграция 00010: племенные документы

00010 добавляет «Заключение о вязке» и «Акт о регистрации помёта».
Итого одиннадцать document_type, 72 строки в 17 справочниках. Для свидетельства
используется прежнее «Регистрационное свидетельство». Даты регистрации старым
собакам автоматически не заполняются. Исходный seed 00002 не изменён.

## Миграция 00011: документы мероприятий

00011 добавляет «Список участников мероприятия» и «Протокол мероприятия».
Всего 13 document_type, 74 значения в 17 справочниках. Для event_diploma повторно
используется «Диплом»; старые дипломы не получают event_id автоматически.
Исходный seed 00002 не изменён, личные данные не добавляются.
