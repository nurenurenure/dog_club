# Каталог начального наполнения

Подборки согласованы пользователем в чате перед загрузкой. Это стартовый
набор справочников, а не полный отраслевой классификатор. Карточек людей,
собак, мероприятий и медицинских процедур в seed нет.

Согласованные предложения агента отмечены отдельно от значений документов.
ID внутри каждой таблицы начинаются с 1 в приведённом порядке; бизнес-логика
не должна зависеть от этих чисел. После вставок последовательности синхронизируются.

## dog_status

Предложено агентом, согласовано пользователем.

На учёте; Снята с учёта.

## breeding_status

Предложено агентом, согласовано пользователем.

Запланирована; Проведена; Отменена.

## membership_status

ТЗ, PDF стр. 14; названия согласованы.

Активный; Неактивный.

## dog_breed

Предложено агентом, согласовано пользователем; стартовый, не исчерпывающий список.

Лабрадор-ретривер; Немецкая овчарка; Бигль.

## coat_color

Предложено агентом, согласовано пользователем; без правил сочетания с породами.

Чёрный; Белый; Рыжий; Чёрно-подпалый.

## identifier_type

Предметная область, PDF стр. 2.

Микрочип; Татуировка; Идентификационная бирка.

## document_type

Предметная область, PDF стр. 2–3.

Ветеринарный паспорт; Родословная; Регистрационное свидетельство; Ветеринарная справка; Сертификат; Диплом; Документ о результатах обследования.

## event_type

Предметная область, PDF стр. 4.

Выставка; Соревнование; Занятие; Форум; Конференция; Семинар.

## event_class

Предметная область, PDF стр. 4; без возрастных границ и правил допуска.

Класс бэби; Класс щенков; Класс юниоров; Промежуточный класс; Открытый класс; Класс чемпионов; Класс ветеранов.

## grade

Предметная область, PDF стр. 4.

Отлично; Очень хорошо; Хорошо; Удовлетворительно.

## title

Предметная область, PDF стр. 4; без условий присвоения.

Юный чемпион; Чемпион; Гранд Чемпион; Чемпион породы; Интернациональный чемпион.

## training_type

Предметная область, PDF стр. 3.

Обучение послушанию; Подготовка к соревнованиям; Подготовка к выставкам; Социализация.

## contact_type

ТЗ, PDF стр. 7.

Телефон; Email.

## address_type

ТЗ, PDF стр. 7.

Адрес проживания.

## role

ТЗ, PDF стр. 13; справочник не реализует авторизацию.

Администратор; Сотрудник клуба; Ветеринар; Эксперт-кинолог; Владелец собаки; Руководитель клуба.

## sex

Пол из физической модели; термины для начального справочника.

Кобель; Сука.

## disease

Предметная область, PDF стр. 3; только названия, без клинических характеристик.

Чума плотоядных; Парвовирусная инфекция; Аденовирусная инфекция; Бешенство; Лептоспироз; Бордетеллиоз; Парагрипп.

## vaccine_type

Пустой по согласованию пользователя. Единица `validity_period`, препараты,
производители и сроки действия требуют отдельного решения и проверки источников.
Названия заболеваний не заменяют конкретные препараты вакцин.

## Откат

Down удаляет только начальные ID и не использует CASCADE. При наличии ссылок
из рабочих записей PostgreSQL отклонит откат. Полный откат схемы удаляет данные
и проверяется исключительно в одноразовой тестовой БД.
